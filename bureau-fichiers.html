📚 Les extensions de fichiers

🔤 C'est quoi une extension ?

C'est la partie après le dernier point dans le nom du fichier. Dans musique.mp3, l'extension est .mp3.

🎮 C'est comme une étiquette sur une boîte : .mp3 = musique, .pdf = document.

📏 Les unités de taille

ko → un SMS
Mo → une photo
Go → un film
To → des centaines de films
1 To = 1 000 Go = 1 000 000 Mo

📋 Extensions courantes

.txt — Texte brut
.pdf — Document portable
.doc / .docx — Word
.xls / .xlsx — Excel
.mp3 — Audio compressé
.flac — Audio haute qualité
.avi / .mov — Vidéo
.html — Page web
.zip / .tar — Archive
.tif / .jpg / .png — Images
.pub — Publisher
.mpp — Project

❓ Extensions inconnues

Sur ce bureau, plusieurs fichiers ont des extensions inventées (.cca, .luc, .ryt, .kit, .be, .rbt…). Repère-les !

⚠️ Dans la vraie vie, ne jamais ouvrir un fichier inconnu reçu par e-mail — c'est souvent un virus !
